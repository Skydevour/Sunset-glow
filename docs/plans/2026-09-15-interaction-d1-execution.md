# D0 / D1 角色与环境交互实施

用户已要求依据 2026-09-14-character-environment-interaction-spec 开始实现，并提供两张角色图。原规格“本轮仅更新文档”和“参考图缺失”描述已过时，不作为阻止开发的指令。

本工作包：整理参考与资产；共享 WindField、SurfaceQuery、FootContactEvent；原生 HDRP 水面查询/局部扰动；浅水行走技术验证。首版接触来自真实位移回退，正式角色动画到 D3 接入，声音与脚印由 D4 消费同一事件。

顺序：接口实现 → 集成现有独立场景 → 构建运行 → 故障/暂停/去重/池容量验证 → 实际水纹画面及60秒云移动序列 → 新增性能测量。不能以文档或编译通过替代实际效果检查。

新增渲染仍属于天气预设联动；世界时钟、天气存档与 P0 长期验收不提前勾选。人物正式源资产与绑定、树木分层风动、沙雪脚印及脚步素材，按 D2—D6 的后续工作包继续。
