# 云、植被与参考角色细化

依据用户本轮反馈直接实施。旧 D1 的水面/接触接口保留；之前含天气过渡的云序列不能作为云平移验收。

1. 云：核查 HDRP 实际路径，保持固定天气和镜头观察连续位移，验证暂停恢复。保留正常表现时间。
2. 植被：改进主干、分叉、小枝和叶簇的几何层级，分层风动、稳定树根与碰撞，保留季节材质与 LOD。
3. 主角：根据两张原图制作可编辑 Blender 源文件、绑定 FBX 与 Unity Prefab，细化遮眼长发、蓝紫眼睛、马耳、白花头饰、长袖围裙和裙褶。未见背面及鞋款为首版补全。
4. 集成：替换可见方块，保留单一玩家控制器；提供全身查看与第一人称模式。
5. 验证：实际 Player 正侧背/脸部、森林与固定云序列截图；重新构建并采集性能。不将模型首稿称为最终美术验收。
