# 角色与环境交互 D0 / D1 结果

2026-09-15，依据用户指定规格及两张角色图开始实施。本工作包交付共享接触/风场接口和可运行的水面技术小样，不是整个 D0—D6 专项完成。

## 已实现

- WindField 统一水平吹向、m/s、空间阵风相位及短弧方向过渡；云、海浪和雪读取同一状态，HDRP 接口转换为 km/h。云与大浪分别滞后响应，暂停保留表现相位。
- SurfaceQuery 以真实碰撞点判定水、雪、湿沙与基底。地形雪覆盖公式供材质生成与表面查询共用，不用雪粒子播放状态推断地面覆盖。
- FootContactEmitter 按接地后的实际水平位移发出左右脚事件。撞墙、站立、悬空、暂停和传送不产生回退脚步；动画事件入口与距离回退互斥。关闭镜头晃动不再关闭身体摆动或脚步。
- HDRP CPU 水面查询每帧最多 4 次，附近有效缓存可保留 0.4 秒，失效返回明确无效状态。浅滩增加海床碰撞，角色随水深减速，保留异常/超深回岸。当前深水处理为安全复位小样，尚非最终深水边界交互。
- 同一脚步事件驱动原生 WaterDecal 高度扰动；最多 32 个池化波纹，正常表现时间扩散消退，暂停不演进。没有用悬浮透明片代替海面位移。
- 角色图已核对并记录可见特征、不可见背面/鞋袜设计与 D3 制作路线。本机存在 Blender 5.2，工程内没有现成可用人物模型/绑定/动画。

## 实际验证

`artifacts/interaction/capture2/validation.json` 全部通过，零运行错误；其中 41 次有效接触覆盖干沙、雪、水及停止/碰撞/暂停/传送去重。风向 359°→1°短弧、阵风空间相位、水查询失败缓存/过期/恢复和查询预算通过。

从岸边 x=48 连续走至 x≥67.5 不复位，脚步产生水纹，停步不新增。原生水面形变缓冲 GPU 回读从 0 增加到 0.0289307 米；实际 PNG 中可见水纹。池上限与旧波纹消退通过。

`cloud-wind-000`—`030` 是跨度 60 秒、每 2 秒一帧的运行序列。`artifacts/interaction/cloud-wind-60s.gif` 按真实采样时间播放；前段包含冬季转晴天，随后可观察云平移。这是时间序列记录，不是高帧率视频，不能据此宣布快速转头/TAA 或完整 D2 通过。

性能：本机 i7-14700KF、RTX 4070 Ti SUPER、32GB，DX12/1080p/Coastal HDRP/Development Player。冬季浅海固定机位预热15秒、采样60秒，11,974帧全焦点，零错误/警告；平均5.011ms，P95 8.341ms，P99 9.146ms，最大16.517ms，GPU平均4.545ms。证据 `artifacts/interaction/benchmark/`。这是 D1 固定机位基线，不是 D6 三条连续行走路线、10分钟池稳定性或全部效果 A/B 验收。

## 运行与后续

接入后的 M1 回归也已通过：`artifacts/interaction/m1-regression/validation.json` 中 38 项检查全部通过、零运行错误，覆盖原有观察点、行走碰撞与室内遮蔽。异常深水复位测试保留，浅水可行走由上述 D1 测试独立覆盖。

构建 `Builds/M1/IslandPrototype.exe`；场景 `Assets/_Game/Scenes/IslandPrototype.unity`。1/2/3切换环境预设，7/8/9切换无风/微风/阵风目标；WASD走入浅海，Escape暂停。菜单 `Sunset Glow/Interaction/Configure D1 and build` 可重建接入；Coastal重新生成在检测到交互系统时会重新绑定，不丢失已接入接口。

正式人物源模型、蒙皮、动画与Prefab尚未制作，当前可见身体仍为技术占位。树木分层风动、脚印和脚步音效尚未交付；D2/D3可在本接口基础并行，D4/D5继续完成反馈。统一世界时间/天气存档/48分钟P0验收也未被本小样替代。
