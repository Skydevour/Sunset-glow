# 云、植被和参考角色细化记录

2026-09-15，针对用户指出云不动、植被粗糙和缺少参考角色的问题实施。此记录不代替完整 P0 / D3 / D6 验收。

## 实现

- 云主体按共享 WindField 表现时钟显式平移，关闭 HDRP 原生主体重复位移。高空风平滑响应，不重置天气切换相位；暂停冻结。降低形状重复感、增加内部明暗与侵蚀细节，采用 96 主步/8 光照步采样。
- 树木现在包含根盘、弯曲主干、主次枝和立体针叶束；修正圆筒面绕序，增加平滑树干法线、纵向树皮纹理。近远 LOD 保留主干。草使用短细折脊叶片、疏密簇分布；地面增加土斑、树下腐殖质和细碎枯针。
- 树/草读取同一风场，固定根部、不同高度/枝梢权重与实例相位。可见距离与24/12/6Hz调度，全局每帧180k顶点预算、草网格每块90k以内；碰撞保持原有静态结构。CPU网格变形并非GPU顶点风动，成本单独实测。
- 按两张用户原图制作可编辑 Blender 角色、绑定 FBX 和 Prefab：68,818三角面、36,762顶点、61骨骼、6蒙皮网格、10材质。包含遮眼厚发束、蓝紫虹膜、耳朵、白花头饰、长袖围裙褶裙和独立手指。后腰蝴蝶结、鞋袜为未见区域的首稿补全。
- 站立/行走为Generic原地动作，单一玩家控制器负责移动；第一人称隐藏头/发/头饰但保留影子，眼位匹配模型。V切换角色查看，左右方向键绕看，再按V返回。修复退出查看模式鼠标未锁定的问题。
- Blender线性色值转换到HDRP颜色输入，衣物增加程序化织物微法线。未交付手绘贴图、服装碰撞、完整跑步/转向/涉水动作或Humanoid重定向验收，不将首稿称作最终角色还原。

## 证据与可复现入口

- `art-source/character/RiceShower.blend`、`build_rice_shower.py`、`README.md`：可编辑来源与重建说明。两张用户图备份在同目录 `references/`。
- `artifacts/character/skin-validation.json`：全部顶点权重归一、骨名有效，最多3权重。该项验证来自Blender，独立于Unity运行。
- `artifacts/refinement/cloud-final/`：固定晴天、固定镜头的60秒序列，之后暂停5秒并恢复。零运行错误，天空像素平均变化0.086236，暂停0.002123，恢复0.013655；暂停时云位移相位保持不变。
- `artifacts/refinement/cloud-motion-60s.gif`：实际Player每5秒采样一帧，按5秒/帧播放，不是连续高帧率录像。
- Unity菜单 `Sunset Glow/Refinement/Build detailed environment and character`：重建环境、接入角色并构建 `Builds/M1/IslandPrototype.exe`。M1重新生成时会优先复用角色Prefab。

角色源预览与游戏内截图分别存放，运行画面仍需逐项人工审阅；零错误或参数位移不自动等于视觉验收。
